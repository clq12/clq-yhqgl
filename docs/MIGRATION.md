# v2 → v3 迁移指南

本文面向**老用户 / 老数据**：原先 v2 架构把数据存在本地 `data.json`（WebDAV 同步中枢），
v3 改为「云端数据库为唯一真相源」。下文说明如何把历史数据搬到云端，以及迁移时的取舍。

> 协议细节见 [shared/rules/sync-protocol.md](./sync-protocol.md)；架构见 [docs/ARCHITECTURE.md](./ARCHITECTURE.md)。

## 1. 为什么迁移

| 维度 | v2（已废弃） | v3（当前） |
|------|------------|-----------|
| 同步通道 | WebDAV 三向合并 + 向量时钟 | 云端数据库（乐观锁 + 软删除） |
| 真相源 | 各端本地 `data.json` | 云端 `coupons` / `settings` |
| 冲突 | 字段级合并（易丢数据） | 整条拦下进「待解决」 |
| 跨设备 | 需自建 WebDAV 网盘 | 同邮箱账号登录即用 |

v2 的实际问题：网页端从未真正接入 WebDAV 协议，结果是两份互不可见的数据。
v3 直接砍掉这层抽象，登录同一邮箱即可跨设备访问同一份数据。

## 2. 老数据在哪

v2 的老数据在：

- **网页端**：浏览器 IndexedDB（库名 `clq-yhqgl-v2`，`coupons` store）。
- **安卓端**：App 私有目录 / 或你此前备份到 WebDAV 的 `data.json`。

> 注意：v2 的 WebDAV `data.json` 与 v3 的「手动备份」`data.json` **不是同一个东西**。
v3 的备份只是本地快照，不参与同步；请勿把 v2 的 `data.json` 直接当 v3 备份恢复。

## 3. 迁移步骤（手动，可复现、不丢数据）

### 3.1 网页端 → 云端

1. 打开网页端（确保用 **同一浏览器、同一设备**，能读到旧 IndexedDB）。
2. 用邮箱验证码登录（同一账号即同一份云端数据）。
3. 首次登录会弹**迁移三选**之一：
   - **上传本地**：把本机 IndexedDB 里的券推上云（适合「这台电脑是唯一数据来源」）。
   - **只拉云端**：丢弃本机旧数据，以云端为准（适合已在别处迁移过）。
   - **先清空再拉**：本机旧数据全删，纯拉云端（适合本机数据已脏/重复）。
4. 选「上传本地」后，等待同步完成（设置页「账号与同步」会显示「云端已有 N 条记录」）。
5. 验证：换设备/清缓存重新登录，确认券都在。

### 3.2 安卓端 → 云端

- Android 端 `CloudSyncEngine.initialMigration(MigrationMode)` 已支持上述三选，
  在首次登录弹窗里选择即可，逻辑与网页端一致。
- 若旧数据在 WebDAV 备份里（v2 的 `data.json`），**不要**直接「从 WebDAV 恢复」——
  那会覆盖云端。正确做法：先在网页端/安卓端用「上传本地」把当前设备的活数据推上云，
  v2 的 WebDAV 备份仅作为兜底存档保留即可。

## 4. 取舍与风险

- **提醒状态不迁移**：`isReminded` / `remindedDays` 是**本地**字段，不参与云端同步。
  换设备后提醒会从零计起（按设备各算），这是设计使然，不是丢数据。
- **软删除优先**：迁移时如果某张券在本地已软删除（`deleted_at` 非空），上云后仍是删除态，不会复活。
- **乐观锁冲突**：如果同一张券在云端和本地都被改过，本地写入会被拦下进「待解决」，
  不会静默覆盖——在「待解决」列表里选「以云端为准」或「覆盖」即可。
- **换账号**：登录新账号前，旧账号的本地残留会被清掉（`owner_id` 不匹配），不会串号。
  若想保留旧账号数据，请先用旧账号登录并完成上传，再退出登录新账号。

## 5. 验证清单

- [ ] 登录后设置页显示「云端已有 N 条记录」，N 与本地券数一致。
- [ ] 退出登录→游客模式数据仍在本地；再登录同账号自动合并。
- [ ] 换设备登录同一账号，券完整可见。
- [ ] 软删除的券在任意设备都不出现。
- [ ] 提醒状态按设备各算（一端提醒过另一端仍会提醒）。

## 6. 回滚

v3 不改变本地数据格式，迁移前的数据仍留在本机 IndexedDB / Room 缓存里，
不上传即可保持原样。若对云端数据不满意，退出登录后本机旧数据仍在；
如需查看被放弃的 v2 方案（WebDAV 同步中枢 + 字段级合并），见 `git log -- docs/REFACTOR_ANALYSIS.md`——
该文档已删除，不再随仓库分发，避免有人照着它实现。
